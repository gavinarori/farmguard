# FarmGuard

FarmGuard is a farm weather application built with Next.js that helps farmers monitor weather conditions and make informed decisions for their agricultural activities. The platform provides real-time weather information, forecasts, and environmental insights through a simple and responsive dashboard.

## Features

* Real-time weather monitoring
* Multi-day weather forecasts
* Location-based weather insights
* Responsive dashboard for desktop and mobile devices
* Fast and modern user experience powered by Next.js

## Repository

GitHub Repository: https://github.com/gavinarori/farmguard

Clone the repository:

```bash
git clone https://github.com/gavinarori/farmguard.git
cd farmguard
```

## Getting Started

### Prerequisites

* Node.js 18 or later
* npm, yarn, pnpm, or bun

### Installation

Install project dependencies:

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the application.

## Build for Production

```bash
npm run build
npm start
```
